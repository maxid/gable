# Roadmap

- [x] Explicit container and module lifecycle
- [x] Typed configuration (YAML + environment)
- [x] `glogs` logger
- [x] Stable error codes
- [x] Web MVC, binding/validation, response envelope
- [x] springdoc-shaped OpenAPI 3.0.1 and Swagger UI
- [x] Namespace: gns config, app exposure, cache/auth integration, gcache/gbus adoption
- [x] Tenant: single/saas modes, host login rules, fail-closed scope, impersonation
- [x] ORM core: models, query builder, CRUD, tenant guard, gcosid keys, AutoMigrate (MySQL/PostgreSQL)
- [ ] ORM: relations/Preload, soft delete/retain, ClickHouse/DM/TDengine dialects
- [x] Pilot: tenant-scoped task board (single/saas, memory/ORM, OpenAPI)
- [x] DSL: Model/Table/Form/Page, lint, DDL/IR preview, idempotent apply (file store)
- [x] DSL: runtime data API (/dsl/data/<model>) with tenant guard and vamis params
- [x] DSL: MCP tools (schema/lint/preview/apply)
- [ ] DSL: database store, diff/revision, Api/Mcp kinds
- [x] Auth core: password, JWT/opaque access, opaque refresh rotation, bearer middleware
- [x] Passport-compatible Login/refresh/logout + OAuth2 token/introspection/revocation endpoints
- [x] OAuth2 client: authorization code + PKCE
- [x] OAuth2 authorization server: authorize + code + PKCE + consent + metadata
- [x] Social login callbacks (/oauth2/login|callback/:provider)
- [x] OIDC id_token/JWKS/userinfo (RS256)
- [ ] Cookie sessions, MFA
- [x] `rpc`: local + HTTP/JSON bindings with a resolver port (Nacos adapter lives with the deployment)
- [ ] `gai` and `gmcp` adapters
- [ ] Low-code resources compiled to the LCDP IR
- [x] CLI: `new`, `dev`, `version`
- [ ] CLI: `gen`, `migrate`
- [ ] v1.0 API stabilization
