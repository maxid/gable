# Roadmap

- [x] Explicit container and module lifecycle
- [x] Capability plugins: `gplugin.Set` selection, manifests, optional lifecycle (moved to [`gplugin`](https://github.com/maxid/gplugin))
- [x] Typed configuration (YAML + environment) with a validating hot-reload watcher
- [x] `glogs` logger
- [x] Stable error codes
- [x] Web MVC, binding/validation, response envelope
- [x] springdoc-shaped OpenAPI 3.0.1, Swagger UI and `x-...` vendor extensions per operation
- [ ] springdoc golden comparison against a Java sample (blocked: needs the Java backend)
- [x] Namespace: gable prefix config, gns context/Store SPI, gcache-backed Store adapter
- [x] Tenant: single/saas modes, host login rules, fail-closed scope, impersonation
- [x] ORM core: models, query builder, CRUD, tenant guard, gcosid keys, AutoMigrate (MySQL/PostgreSQL)
- [x] ORM: relations (`belongs_to`/`has_many` + `Preload`), soft delete/retain guards with `Restore`/`Purge`
- [x] ORM: `WithTx` transactions with repositories bound to the transaction
- [ ] ORM: ClickHouse/DM/TDengine dialects
- [x] Pilot: tenant-scoped task board (single/saas, memory/ORM, OpenAPI)
- [x] DSL: Model/Table/Form/Page, lint, DDL/IR preview, idempotent apply (file store)
- [x] DSL: runtime data API (/dsl/data/<model>) with tenant guard and vamis params
- [x] DSL: MCP tools (schema/lint/preview/apply)
- [x] DSL: database store (`NewDBStore`: migrate/load/save, one row per resource, every write kept in a revision table), `gable dsl push`, `serve --load db`
- [x] DSL: diff/dry-run, revision history and restore over the database store
- [x] DSL: Api/Mcp kinds (bind actions and tools to registered Go handlers, named guards, bind-time validation)
- [x] Auth core: password, JWT/opaque access, opaque refresh rotation, bearer middleware
- [x] Passport-compatible Login/refresh/logout + OAuth2 token/introspection/revocation endpoints
- [x] OAuth2 client: authorization code + PKCE
- [x] OAuth2 authorization server: authorize + code + PKCE + consent + metadata
- [x] Social login callbacks (/oauth2/login|callback/:provider)
- [x] OIDC id_token/JWKS/userinfo (RS256)
- [x] Cookie sessions and MFA (TOTP + one-time recovery codes, login ticket)
- [x] `rpc`: local + HTTP/JSON bindings with a resolver port (Nacos adapter lives with the deployment)
- [x] `mcp`: operations as MCP tools over HTTP (shared-key transport check)
- [x] `ai`: tool-calling conversation loop over `gai` (bounded rounds and history)
- [ ] Low-code resources compiled to the LCDP IR
- [x] CLI: `new`, `dev`, `version`
- [x] CLI: `migrate` (DSL models → missing tables, `--dry-run` prints the DDL)
- [x] CLI: `inspect` (effective config with the DSN password redacted, derived namespace names, DSL summary)
- [x] CLI: `gen dsl` (Model resources from gable-tagged Go structs, idempotent, warns on fields it cannot express)
- [x] Validation (`validate`), message bundles (`i18n`) and `ctx.Page` with a sort whitelist
- [x] Observability: liveness/readiness registries, `/healthz`, `/readyz`, Prometheus-text `/metrics` with request and latency instruments
- [ ] v1.0 API stabilization
